X mentions and reviewed replies

Replies are off by default. This inbox keeps only post IDs, conversation IDs, and timestamps; open each mention on X to read it. Social content is untrusted input and is never used as evidence. An operator must classify an in-scope dated-fact request, select a current assessment, review the exact response, and explicitly queue it. Ambiguous questions, corrections, abuse, and unsupported requests should be escalated.

The collector uses the account-bound user token, reserves a bounded mentions read before each API call, verifies account identity when the token changes, and discards post text. X access-plan entitlements and credit availability still need live qualification.
