Social listening · X

Search public X posts for potential leads about Nigerian household prices and policies. Results are unverified leads, never evidence or claims. AfricaSignal stores post IDs and links only; it does not retain post text or account profiles. Open the post on X to review its current content.

This uses X Recent Search, which covers the last 7 days and allows up to 100 results per request. Reads can consume X account credits. The daily cap below is a resource cap; X billing and credit limits remain authoritative. Search calls use the configured application bearer token, not the publishing account token.
