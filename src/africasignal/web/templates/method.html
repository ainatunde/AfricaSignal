How assessments work

AfricaSignal tells you what changed, how sure we are, and where the evidence is. Here is exactly how.

What we publish

Each page is an assessment of one situation: for example the average petrol price in Lagos State. Every number on a page is calculated by code from source documents we keep a copy of. Headlines are written from templates, not by an AI. Where we add a plain-English explanation written by an AI, it may only use the numbers already on the page, and it is dropped if it fails our checks.

For policy changes, “Official statement” means a regulator or government document says so. We report what it says; we do not claim it is what people are paying.

When we hold something back

  • Publication is paused by an operator (the page shows a banner).
  • A figure has no source document behind it, or the document has been withdrawn.
  • A new value looks wrong compared with earlier ones (for example a price that jumps tenfold) and a person has not confirmed it.
  • The place is more precise than the source allows. A state average is never shown as the price in a local government area.
  • A very large first-time change waits up to an hour for a person to look at it, then goes out unless it is stopped.
  • If the last figure is more than 120 days old, or there is no earlier month to compare with, the page says there is not enough evidence.

Possible factors and what we don't know

We list things that can move a price, such as the exchange rate. A factor is marked “supported” only when a report we collected links it to this change. Otherwise it says “not checked”. We never state a cause as fact without that link. Each page also lists what we do not know, for example that a state average may differ from prices in your area.

Staying current

Each assessment has a “valid until” date. After it passes, the page says “Out of date” and we check again.

Corrections

If a source revises a figure or a document is withdrawn, we recalculate. The corrected version replaces the old one, the version history of each page keeps the old version and says what changed, and if nothing valid remains the assessment is withdrawn with a reason.
